ELI5 Learner · Android companion · one-time setup

Connect your Mac and Pixel through your own Google Drive

About 20 minutes of clicks in the Google Cloud console. There's no server to run: your documents sync through a hidden app folder in your Drive, and nothing you create here ever goes into the public repository.

01

Create the Google Cloud project

Sign in to the console with the Google account you'll use on both devices. Tick each step as you go; your progress is remembered in this browser.

  1. Create a project

    Any name works, for example ELI5 Learner personal.

    console.cloud.google.com/projectcreate ↗

  2. Enable the Google Drive API

    APIs & Services → Library → search Google Drive API → Enable.

    Google Drive API in the library ↗

  3. Branding

    Google Auth Platform → Branding. App name ELI5 Learner, your email as support and developer contact. Don't upload a logo; it triggers a brand review.

  4. Audience

    User type External. Leave publishing status on Testing for now, and add your own Gmail address under Test users.

  5. Data access: three scopes, nothing more

    Add exactly these. Never add the full drive scope.

    openid
    https://www.googleapis.com/auth/userinfo.email
    https://www.googleapis.com/auth/drive.appdata

  6. Create three OAuth clients

    Google Auth Platform → Clients → Create client, three times:

TypeWhat to enterWhat you keep
Desktop appName: ELI5 Learner desktopDownload the JSON (client_secret_….json). Keep it outside the repo, for example in Downloads.
Android (release)Package io.github.eli5learner + the release SHA-1 belowNothing. Google matches the app by package name and signing key. This is the one the APK you'll install uses.
Android (debug)Package io.github.eli5learner + the debug SHA-1 belowNothing. Only needed if you install debug builds.

These are public certificate fingerprints, not secrets. They come from the signing keys on your Mac (~/.config/eli5-learner/eli5-release.jks and ~/.android/debug.keystore). Back up the release keystore: every future APK must be signed with it, or the phone refuses the update. You can re-print them any time with ./gradlew :app:printOAuthFingerprints. A mismatch shows up on the phone as "Developer error (10)".
02

Connect both apps

On the Mac

  1. ELI5 Learner → Settings → Sync.
  2. Drop the downloaded Desktop client JSON on the Google client field. It goes into the macOS Keychain.
  3. Click Connect Google Drive and allow access in the browser.
  4. Turn on Sync, and Accept jobs from phone if you want to send links from the Pixel.

On the Pixel

  1. ELI5 Learner → Settings → Connect Google Drive.
  2. Pick the same Google account and allow access.
  3. It shows "Waiting for your Mac…", then downloads your library.
  4. Share any link or photo to ELI5 Learner → Send to my Mac. The Mac app must be running (the menu bar is enough).
03

Once it works: publish the app

In Testing, Google signs both devices out every 7 days. When sync works, go to Audience → Publish app. The app asks only for non-sensitive scopes, so there's no review. Google may still show "Google hasn't verified this app"; as the owner you can continue past it.

04

Where your data goes

A hidden app folder in your Drive. You can't browse it, other apps can't read it, and it counts against your storage. It holds your documents with their titles and summaries, not your source files. It isn't end-to-end encrypted. To remove it: Mac Settings → Sync → Delete cloud copy. To revoke access entirely: myaccount.google.com/permissions. Your Mac's library is never affected.
