Security advisory: remote code execution in Example Widgets Gateway 3.2

Synthetic page for evaluation. Example Widgets Inc. and its products are fictional.

A flaw in the file upload handler of Example Widgets Gateway versions 3.0 to 3.2 lets an unauthenticated attacker run code on the gateway (remote code execution, RCE). It is tracked as CVE-2026-0142 and rated 9.8 on the CVSS scale, which runs from 0 to 10.

Who is affected

About 2,100 gateways are exposed to the internet, according to the vendor. Gateways reachable only from an internal network are at lower risk, because the attacker must first get inside that network.

What to do

  1. Upgrade to version 3.2.1, released on 12 May.
  2. If you cannot upgrade within 72 hours, turn off the upload feature in the admin panel.
  3. Check gateway logs for upload requests to /api/v1/import from unknown addresses.

Exploitation

The vendor has seen exploitation in the wild against 14 customers since 9 May. Attackers used the flaw to install a cryptocurrency miner. There is no sign they moved from the gateway to other systems.
